# JavaScript Course

This project is a simple HTML page for a JavaScript learning course.

## Project contents

- `index.html` contains the page structure and a basic JavaScript example.
- The page displays the title "JavaScript Course" and logs a message to the browser console.

## How to run

1. Open `index.html` in a browser, or
2. Serve the folder locally with a simple HTTP server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.

## Notes

This is a minimal starter project for learning the basics of JavaScript and HTML.
